REQUIRED FILE: gsx2026.mind

The included PNG is the reference art for the BACK side of the GSX 2026 coin.
MindAR does not track the PNG directly at runtime. It uses a compiled feature file.

1. Open the official MindAR Image Targets Compiler:
   https://hiukim.github.io/mind-ar-js-doc/tools/compile/

2. Upload:
   gsx2026-coin-reference.png

3. Click Start and review the feature-point visualization.

4. Download the generated targets.mind file.

5. Rename it:
   gsx2026.mind

6. Place it in this folder:
   assets/targets/gsx2026.mind

For production, compile from a clean, straight-on, evenly lit photograph or final artwork
that closely matches the actual minted coin. Metallic glare can reduce tracking quality.
